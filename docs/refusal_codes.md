# Refusal codes

Generated by `scripts/build_refusal_docs.py` from `surface/refusal.py`'s `RefusalCode` enum -- do not hand-edit, regenerate instead.

Every refusal `surface/gate.py` produces carries one of these codes, a specific human-readable detail string, and a structured `context` dict for the audit trail. "Refusals are logged as richly as successes" (see `docs/CLAUDE.md`).

## auth

| code | description |
|---|---|
| `invalid_signature` | The Intent Mandate's Ed25519 signature does not verify against its claimed public key. |
| `mandate_expired` | The Intent Mandate's expiry timestamp has passed. |

## policy

| code | description |
|---|---|
| `over_price_ceiling` | The proposed cart total exceeds the Intent Mandate's max_amount. |
| `category_not_allowed` | A requested SKU's category is outside the Intent Mandate's allowed_categories. |

## compatibility

| code | description |
|---|---|
| `incompatible_item` | pipeline/verify.py could not verify a claimed compatibility relationship for a requested item. |
| `unverified_compatibility` | A compatibility claim exists but carries no machine-checkable proof (e.g. the underlying attribute is quarantined). |

## availability

| code | description |
|---|---|
